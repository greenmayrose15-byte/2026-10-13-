🚀 DayLog 시작 가이드

1

앱 선택 및 시간 기록

VS Code, Chrome 등 작업 중인 애플리케이션을 선택하고 실시간 타이머를 시작하거나 수동 시간(분)을 입력해 기록합니다.

2

마크다운 일기 & 세부 작업 메모

단순한 시간 기록뿐만 아니라 마크다운 문법으로 작업 내역, 체크리스트, 감정 일기 등을 자유롭게 남길 수 있습니다.

3

7일 주간 리포트 및 지표 분석

일별 사용 시간 막대 그래프, 연속 기록일(Streak 🔥), 가장 많이 쓴 앱(Top 1), 일일 평균 시간과 목표치 달성률을 한눈에 파악합니다.

4

안전한 100% 로컬 저장 & PIN 보안

서버로 데이터를 전송하지 않으며 모든 데이터는 브라우저 내부(localStorage)에 안전하게 보관됩니다. 필요 시 PIN 잠금 및 JSON 백업을 활용하세요.

처음이라 화면이 비어있다면, 7일치 풍성한 테스트 데이터로 즉시 체험해보세요!

🛡️ 개인정보처리방침 (Privacy Policy)

1. 로컬 데이터 원칙 (Local-First)

DayLog는 사용자의 개인정보와 프라이버시를 최우선으로 존중합니다. 애플리케이션 사용 시간 로그, 작업 메모, 통계 등 모든 데이터는 사용자의 로컬 브라우저 저장소(IndexedDB / localStorage)에만 저장되며 외부 서버나 타사 분석 도구로 일절 전송되지 않습니다.

2. 수집 및 보관 정보

  • 선택한 애플리케이션 이름 및 카테고리
  • 사용 시작/종료 시각 및 누적 소요 시간
  • 사용자가 직접 작성한 메모, 일기 및 태그
  • 설정한 하루 목표 시간 및 보안 PIN (해시 형태)

3. 데이터의 백업 및 파기 권한

사용자는 언제든지 설정 메뉴에서 전체 데이터를 JSON 파일 형태로 직접 내보내어 백업하거나, 즉시 전체 초기화(영구 삭제)할 수 있는 완전한 통제권을 가집니다.

4. PWA 및 오프라인 기능

본 앱은 오프라인에서도 완전하게 동작하도록 서비스 워커(Service Worker)를 구성하고 있으며, 네트워크 연결 없이도 안전하게 독립 실행됩니다.
